# 🎮 GUERRA MUNDIAL Z - FPS 3D

Videojuego tridimensional de disparos en primera persona (First-Person Shooter) desarrollado para el curso de Computación Gráfica y Visual. El objetivo del juego es sobrevivir a oleadas de zombis, administrar munición, y llegar al punto de extracción.

## ⚙️ Tecnologías Utilizadas
- **Lenguaje:** JavaScript (ES6+)
- **Librería Gráfica:** [Three.js](https://threejs.org/) (WebGL)
- **Modelos 3D:** Formato `.glb` cargados mediante `GLTFLoader`.
- **Estructura UI:** HTML5 y CSS3.
